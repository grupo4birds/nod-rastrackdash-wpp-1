# Billing — guia orientado por gateway

Na v1 do RastrackDash **nao ha billing fechado** (Asaas/split PalmUP) para o aluno cobrar o cliente final.

## Opcoes do aluno

1. **Nao cobrar** pelo painel (cobranca manual/externa)
2. **Asaas proprio** (BYO)
3. **Hotmart / outro gateway** (BYO)

## O que o produto oferece

- Conceitos de referencia do WppTrack (`PaymentCharge`, ativacao por pagamento) como padrao mental
- Pontos de extensao no codigo (quando exportado) para plugar adapter de pagamento
- Este guia passo a passo (em evolucao)

## Fora de escopo v1

PalmUP nao opera split nem gateway do aluno. Monetizacao do aluno e responsabilidade dele.
